# Review panels

← [Docs home](README.md)

The review column stays available while you inspect a model. **Clash Review** opens tests, results, navigation, focus and reports. **Inspect** selects and scans elements, measures distance, area, angle or clearance, opens the section box and finds rooms. **Issues** adds comments, opens the comment list and markup, and imports or exports BCF.

Choose a tool with its panel button, then click the model. The cursor stays free; right-drag from the model to rotate the camera. Use each panel's header control to collapse it. On short windows, scroll inside a panel to reach its remaining actions.

See [Comments, markup and BCF](comments-and-bcf.md), [Clash detection](clash-detection.md) and [Controls](controls.md).
